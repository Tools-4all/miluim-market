# 🪖 מילואימרקט

שוק יד שנייה לציוד של מילואימניקים - פרויקט לימודים ב-React.

**לאתר:** https://tools-4all.github.io/miluim-market/

- **React + Vite** - ממשק המשתמש
- **React Router** - מעבר בין עמודים
- **Firebase Authentication** - התחברות עם גוגל
- **Cloud Firestore** - מסד הנתונים: מודעות, תגובות, מועדפים והודעות פרטיות

## הרצה

```bash
npm install
npm run dev
```

צריך קובץ `.env.local` עם הגדרות Firebase - השמות של המשתנים מופיעים ב-`src/firebase.js`.

## העלאה ל-GitHub Pages

```bash
npm run deploy
```

הסבר מלא על כל חלק בפרויקט: [docs/DEFENSE.md](docs/DEFENSE.md)
